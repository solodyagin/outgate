# Подписанный вход gateway

`NewServer` создаёт выделенный HTTP listener для `outgatecall`. Обязательный `AllowedAuthorities` задаёт точные Host/:authority с разрешёнными портами: чужой Host получает 421 до authenticate/policy/replay. Пустой, невалидный или содержащий дубли allowlist отклоняется при создании сервера. Он требует TLS 1.3 и клиентский сертификат от заданного service CA. SPIFFE URI SAN задаёт caller service/instance. `Authenticate` проверяет grant ID, SPKI, отзыв, ключ и лимит caller по состоянию gateway. `Authorize` проверяет текущую policy для подписанных target/path/method, разрешение фонового вызова или JWT-делегирования и отзыв пользователя. Вызов получает срок допуска до пяти секунд и до истечения сертификата или JWT. Runtime callbacks должны работать с актуальными данными и соблюдать отмену context.

После HMAC и issuer JWT listener проверяет подписанную route revision и выбирает маршрут через registry. `Resolve` возвращает ключ получателя и bound transport для точного session handle. Gateway формирует отдельную подпись `outgategateway` для выбранных instance/version/mount, сохраняет escaped URI, исходный query и подписанный пользовательский контекст, а forwarded-поля формирует из ingress. Тело передаётся потоково через выбранный транспорт. Повторный выбор экземпляра и повторная отправка после ошибки отсутствуют.

`OpenSQLiteServer` открывает заранее подготовленный [SQLite verifier store](https://github.com/solodyagin/outgate-sdk/tree/06595216008abf762874ee695bda0a6c269bc25e/replay). Listener проверяет readiness хранилища и резервирует nonce до отправки запроса. После commit он повторно проверяет срок допуска, revision, маршрут и выбранную сессию. При смене владельца более длинного маршрута запрос отклоняется, reservation сохраняется. Повтор и неверная подпись дают 401, запрет политики — 403, устаревшая revision — 409, исчерпание caller quota — 429, недоступность или общая replay quota — 503.

Launcher открывает отдельный TCP listener и поставляет актуальные control/revocation callbacks; lifecycle HTTP/SQLite и квоты соединений может обслуживать `OpenSQLiteRuntime`. Для strip-сессий с включённым response mount rewrite listener сам разрешает локальный `Location` относительно локального URL и добавляет выбранный mount, сохраняя query/fragment и escaping. Абсолютные HTTP(S) URL и network-path ссылки сохраняются; невалидные/небезопасные значения и несколько Location дают 502 до отправки headers. Явные cookie Path получают mount, остальные атрибуты и отдельные Set-Cookie сохраняются; `__Host-` остаются общими для хоста с Path=/, поэтому имена cookie сервисов должны исключать коллизии. Тела, Link и Refresh не меняются. Необязательный `RewriteResponse` заменяет встроенную обработку и обязан соблюдать те же правила; preserve и явно отключённый rewrite не обрабатываются. Discovery и revocations имеют собственные зарезервированные пути и пока возвращают 404 в этом обработчике. Внешний browser listener, полноценный gateway launcher, обновление lease и PostgreSQL остаются отдельной работой.

Локальные проверки включают реальные mTLS-соединения, повтор nonce, неверную подпись, смену маршрута в момент commit, SQLite recovery barrier и сквозную передачу на BoundSession по QUIC/HTTP3 с независимой проверкой новой подписи у получателя.

`OpenSQLiteRuntime` связывает этот listener с заранее provisioned SQLite и положительными `ConnectionLimits` (общий лимит и на IP). `Serve` принимает plain TCP listener и обслуживает только TLS, закрывая лишние соединения до handshake; IPv4 и IPv4-mapped IPv6 считаются одним IP. Runtime владеет listener после первого успешного запуска `Serve`. `Shutdown(ctx)` прекращает приём и дожидается handlers перед закрытием replay store. Если срок shutdown истёк, store остаётся открытым; нужно повторить Shutdown после завершения запросов. Это также обязательно после ошибки Serve. Отсутствующая DB не создаётся автоматически, recovery barrier сохраняется. Лимиты относятся к этому listener; общий бюджет всех ingress, rate limits, загрузка конфигурации и durable security callbacks остаются обязанностью будущего launcher.
